## 1. Overview  

전기차 시장은 연평균 20% 이상 성장하고 있지만,  
국내 충전 인프라 확충 속도는 이에 미치지 못하고 있습니다.  

2025년 전기차 선호도 조사에 따르면 운전자의 **38.5%가 주행거리 제약으로 인한 충전 불편**을 가장 큰 문제로 꼽았으며,  
같은 비율의 **38.5%가 충전소 설치 확대**를 전기차 인프라의 최우선 과제로 지적했습니다.  

**CHAJI**는 이러한 문제를 해결하기 위해  
**실질 전비(Wh/km)**와 **주행 경로 데이터**를 활용하여  
경로상 최적의 충전소를 추천하는 알고리즘을 구현했습니다.  

또한 **무료 주차 여부, 충전 속도(최소/최대 kW), 이용 제한 조건 등**  
다양한 필터링 기능과 직관적인 UI/UX를 제공하여  
사용자가 원하는 충전소를 쉽고 빠르게 탐색할 수 있도록 설계했습니다.

## 2. Architecture  

### 1) 추천 알고리즘 & 데이터 처리  

- **전국 충전소 데이터 수집 및 갱신**  
  - 환경부·한국전력 API를 활용하여 전국 충전소 메타데이터(위치, 타입, 속도, 운영사 등) 수집  
  - 정기 DB 업데이트 및 캐싱 구조 구현  

- **추천 알고리즘 설계**  
  - 단순 거리순 추천의 한계를 극복하기 위해 **실질 전비 기반 주행 가능 거리 계산** 적용  
  - 경로를 5구간으로 분리 후 각 구간별 후보 충전소를 점수화해 최적 추천  
  - 평가지표 : **충전 속도, 신뢰성(충전기 수·고장률), 편의성(무료 주차·이용 제한)**  
  - 웨이포인트 기반 추천 : 경유지 반경 내 대표 충전소 추출 후 우회 시간 반영  

---

### 2) 백엔드  

- **Spring Boot + MyBatis + MySQL** 기반 REST API 서버  
- 주요 기능 :  
  - 사용자 인증 (회원가입/로그인/JWT 세션)  
  - 충전소 데이터 조회·필터링·추천 API  
  - 관리자 페이지 (충전소 데이터 갱신 및 관리)  
  - 경로 탐색 API 연동 → 실시간 충전소 추천 제공  

---

### 3) 프론트엔드  

- **React + Tmap API** 기반 실시간 지도 UI  
- 주요 기능 :  
  - 출발지/도착지 설정 → 경로 탐색 및 충전소 추천  
  - 조건 필터링 (무료 주차, 충전 속도, 충전기 타입, 사업자 선택 등)  
  - 충전소 상세 카드 UI : 충전기 수, 예상 충전 시간, 도착 시 배터리 잔량 표시  
  - 추천 충전소 마커 하이라이트 표시

## 3. Feature (추천 알고리즘 설계)

### [차지차지 핵심 알고리즘 — 경로상 충전소 추천]

**1단계 : 전국 충전소 데이터 호출 및 필터링**  
- 한국환경공단 API 결과를 매일 갱신하여 DB에 저장  
- 사용자 필터 조건(무료 주차, 속도, 사업자 등) 반영 후 충전소 필터링  
- 동일 충전소 내 복수 충전기 데이터를 그룹화  

**2단계 : 후보 충전소 생성**  
- 온도·주행거리 반영 실질 전비 기반 도달 가능 거리 계산  
- 출발지–도달 거리 구간마다 웨이포인트 설정  
- Haversine 공식으로 웨이포인트 근처 충전소 필터링  
- 평가지표 기반 상위 5개 대표 충전소 추출  

**3단계 : 최종 선별**  
- 경로 5구간 각각의 상위 2개 충전소 선정  
- **Tmap API**로 우회 시간이 가장 짧은 충전소 선별  
- DB 기반 충전 속도 최상 충전소 추가 → 최종 5개 충전소 추천  
- 한국환경공단 API 를 통해 실시간 운영 정보 표시

## 5. How It Works  
```
사용자 위치 입력
↓
충전소 API 호출 → 근처 충전소 필터링 및 캐싱
↓
경로 추천 (실질 전비 기준 도달 가능 거리 계산)
↓
사용자 선호 지표 + 우회시간 반영
↓
최종 최적 충전소 추천
```

## 6. Results  

- **실질 전비 기반 추천 알고리즘**  
  - **배터리 한도 내 목적지 도달 가능성 보장**  
  - **우회시간을 고려해 최종 도달시간이 가장 짧은 충전소 우선 추천**  

- **캐싱·DB 동기화 구조 설계**  
  - **공공데이터 API 응답 지연 2.5 초 → 1.7 초 (약 32 % 단축)**  

- **속도·신뢰성·편의성 3대 평가지표 정의** 및 **가중치 모델 도입**으로  
  **개인화된 충전소 추천 체계** 확립
